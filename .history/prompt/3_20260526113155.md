Tugas:

Buat fitur notifikasi ketika user menambahkan produk ke shopping cart pada aplikasi toko online menggunakan Next.js, TypeScript, Tailwind CSS, dan ShadCN UI.

Stack:
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- ShadCN UI

Tujuan:

Memberikan feedback visual yang jelas kepada user setelah produk berhasil ditambahkan ke keranjang agar interaksi terasa lebih responsif.

Gunakan komponen/library yang sesuai:

- ShadCN Toast / Sonner (jika project menggunakan Sonner)
- Button
- Badge
- Card
- Icon (Lucide React)

Perilaku:

Ketika user menekan tombol:

```tsx
Add to Cart
```

atau ikon:

```tsx
ShoppingCart
```

maka tampilkan notifikasi.

## Skenario 1 — Berhasil menambahkan produk

Tampilkan notifikasi:

Title:
```text
Added to cart
```

Description:
```text
{productName} has been added to your shopping cart
```

Tambahkan:

- ikon cart
- jumlah item yang ditambahkan
- feedback visual yang jelas

Contoh:

```text
✓ Added to cart
Nike Air Max has been added to your shopping cart
```

Perilaku:

- Muncul otomatis
- Menghilang otomatis setelah beberapa detik
- Dapat ditutup manual
- Mendukung banyak notifikasi (queue)
- Tidak mengganggu navigasi user

---

## Skenario 2 — Produk sudah ada di keranjang

Jika item sudah ada:

Title:

```text
Cart updated
```

Description:

```text
Quantity updated for {productName}
```

---

## Skenario 3 — Gagal menambahkan produk

Jika terjadi error:

Title:

```text
Failed to add item
```

Description:

```text
Something went wrong. Please try again
```

Perilaku:

- Tampilkan gaya error/destructive
- Tampilkan ikon warning/error

---

## Tambahan UX

Tambahkan action button pada toast:

Button:

```text
View Cart
```

Ketika diklik:

```ts
router.push("/cart")
```

---

Reusable implementation:

Buat helper:

```ts
lib/cart-notification.ts
```

Contoh penggunaan:

```ts
showAddToCartNotification(product)

showCartUpdatedNotification(product)

showCartErrorNotification()
```

Product type:

```ts
interface Product {
    id:number
    name:string
    image:string
    price:number
}
```

Contoh implementasi pada ProductCard:

```tsx
<Button
    onClick={() => handleAddToCart(product)}
>
    Add to Cart
</Button>
```

Flow:

```ts
const handleAddToCart = async(product)=>{
   try{
      addToCart(product)

      showAddToCartNotification(product)
   }
   catch(error){
      showCartErrorNotification()
   }
}
```

Coding rules:

- Gunakan TypeScript
- Gunakan App Router Next.js
- Gunakan Tailwind utility
- Gunakan ShadCN component
- Jangan gunakan inline style
- Hindari kode duplikat
- Buat reusable helper/function
- Gunakan clean code
- Buat mudah di-maintain
- Responsive

Output:

- Tampilkan semua file yang perlu dibuat
- Sertakan path file
- Sertakan kode lengkap
- Jangan gunakan placeholder
- Pastikan kode langsung bisa dijalankan
- Pastikan tidak ada TypeScript error
