Tugas:

Buat fitur untuk menghitung total quantity (jumlah item) pada shopping cart user di aplikasi toko online menggunakan Next.js, TypeScript, Tailwind CSS, dan ShadCN UI.

Stack:
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- ShadCN UI (opsional untuk UI badge/display)

Tujuan:

Menampilkan total jumlah item yang ada di dalam shopping cart secara real-time dan konsisten di seluruh aplikasi (global state / shared state).

---

## Requirement Fungsional

Buat fungsi untuk menghitung total quantity dari seluruh item di cart.

Contoh data cart:

```ts
interface CartItem {
  id: number
  name: string
  price: number
  quantity: number
}
```

Contoh data:

```ts
const cart: CartItem[] = [
  { id: 1, name: "Shoes", price: 100, quantity: 2 },
  { id: 2, name: "T-Shirt", price: 50, quantity: 3 }
]
```

---

## Expected Output Perhitungan

Total quantity:

```
2 + 3 = 5
```

---

## Requirement Fungsi

Buat utility function:

```ts
lib/cart-utils.ts
```

### Function:

```ts
getTotalCartQuantity(cart: CartItem[]): number
```

### Rules:

- Menghitung total dari semua `quantity`
- Tidak menghitung harga, hanya quantity
- Aman jika cart kosong
- Aman jika quantity undefined/null (anggap 0)

---

## Bonus (Highly Recommended)

Buat juga fungsi tambahan:

```ts
getTotalCartItems(cart: CartItem[]): number
```

Perbedaan:

- `getTotalCartQuantity` → total unit item (quantity)
- `getTotalCartItems` → jumlah jenis produk (distinct items)

---

## UI Integration

Tampilkan hasil total quantity di:

- Navbar cart icon
- Cart badge

Contoh UI:

```tsx
<Button variant="outline" className="relative">
  <ShoppingCart />
  <span className="absolute -top-2 -right-2 text-xs bg-red-500 text-white rounded-full px-1">
    {totalQuantity}
  </span>
</Button>
```

---

## State Management (wajib diperhatikan)

Pastikan total quantity:

- Update otomatis ketika:
  - item ditambahkan
  - item dihapus
  - quantity diubah

Gunakan salah satu pendekatan:

- React Context (recommended)
- Zustand (optional)
- Redux (optional jika project besar)
