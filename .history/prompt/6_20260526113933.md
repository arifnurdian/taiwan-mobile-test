Tugas:

Perbaiki bug pada fitur shopping cart di aplikasi toko online, dimana quantity item tidak bisa di-update dalam jumlah kelipatan (multiples).

Stack:
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- ShadCN UI (jika digunakan untuk UI cart)

---

## Problem Description

Saat user mencoba mengubah quantity item di shopping cart (misalnya:

- tambah 1 → OK
- tambah lagi → tidak ter-update dengan benar
- atau input langsung nilai besar seperti 5, 10 → tidak tersimpan / tidak berubah

maka sistem tidak menghitung atau menyimpan quantity secara benar.

---

## Expected Behavior

Quantity harus:

- Bisa ditambah (increment)
- Bisa dikurangi (decrement)
- Bisa langsung di-set ke angka tertentu (misalnya 3, 5, 10, dst)
- Bisa menangani perubahan dalam jumlah besar (multiple update)
- Tidak reset ke nilai sebelumnya
- Tidak double update atau missing update

Contoh:

```ts
Initial: quantity = 1

User action:
setQuantity(5)

Expected result:
quantity = 5

User action:
+3 (increment multiple times or bulk add)

Expected result:
quantity bertambah sesuai total perubahan
```

---

## Requirement Fungsional

Perbaiki logic update quantity pada cart:

```ts
updateQuantity(itemId: number, quantity: number)
```

### Rules:

- Quantity tidak boleh overwrite secara tidak sengaja
- Harus mendukung:
  - direct set value
  - incremental update
- Harus menjaga state tetap konsisten
- Tidak boleh terjadi race condition UI update
- Tidak boleh menyebabkan duplicate update

## Expected Fix Area

Periksa dan perbaiki kemungkinan masalah berikut:

### 1. State mutation issue
- Jangan mutate array langsung
- Gunakan immutable update

### 2. Async state issue
- Hindari stale state
- Gunakan functional update jika perlu

### 3. Double update issue
- Hindari update ganda saat user klik cepat

### 4. Controlled input issue
- Pastikan input quantity selalu sinkron dengan state

---

## UI Behavior Requirement

Jika quantity diubah dari input:

```tsx
<Input
  type="number"
  value={item.quantity}
  onChange={(e) =>
    updateQuantity(item.id, Number(e.target.value))
  }
/>
```

Pastikan:

- Input selalu reflect state terbaru
- Tidak delay atau stuck
- Tidak reset saat re-render
