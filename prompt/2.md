Tugas:

Buat fitur dialog/modal konfirmasi untuk shopping cart pada aplikasi toko online menggunakan Next.js, Tailwind CSS, TypeScript, dan ShadCN UI.

Stack:
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- ShadCN UI

Kebutuhan:

Buat dua jenis dialog:

1. Checkout Dialog
2. Remove Item Dialog

Gunakan komponen ShadCN yang sesuai:
- Dialog
- Button
- Separator
- Scroll Area
- Badge
- Card
- Input (jika diperlukan)

## Checkout Dialog

Dialog akan muncul ketika user menekan tombol:

"Checkout"

Isi dialog:

Header:
- Title:
  "Checkout Order"
- Description:
  "Review your order before continuing"

Body:
Tampilkan ringkasan pesanan:

- List produk:
    - gambar produk
    - nama produk
    - jumlah
    - harga satuan
    - subtotal

- Ringkasan pembayaran:
    - Total item
    - Total harga
    - Ongkir (dummy)
    - Diskon (jika ada)
    - Grand total

Footer:

Tombol:
- Continue Shopping
- Confirm Checkout

Perilaku:

- Dialog dapat ditutup
- Klik area luar dialog menutup dialog
- Tombol Continue Shopping menutup dialog
- Tombol Confirm Checkout memanggil:

```ts
handleCheckout()
```

- Tambahkan loading state saat proses checkout:

Contoh:

- tombol berubah menjadi:
  "Processing..."

- tombol disabled selama proses berjalan

---

## Remove Item Dialog

Dialog muncul ketika user menekan:

ikon delete / tombol remove pada item keranjang

Header:
- Title:
  "Remove Item"

Description:

"Are you sure you want to remove this item from your cart?"

Body:

Tampilkan informasi item:

- gambar produk
- nama produk
- harga
- quantity

Footer:

Tombol:

- Cancel
- Remove

Perilaku:

- Cancel menutup dialog
- Remove memanggil:

```ts
handleRemoveItem(itemId)
```

- Tambahkan loading state:

Contoh:

- tombol berubah menjadi:
  "Removing..."

- tombol disabled selama proses berjalan

Reusable component:

Buat komponen terpisah:

components/
├── CheckoutDialog.tsx
├── RemoveCartItemDialog.tsx

Props CheckoutDialog:

```ts
interface CheckoutDialogProps {
    open:boolean
    onOpenChange:(open:boolean)=>void
    items:CartItem[]
    onCheckout:()=>Promise<void>
}
```

Props RemoveCartItemDialog:

```ts
interface RemoveCartItemDialogProps{
    open:boolean
    onOpenChange:(open:boolean)=>void
    item:CartItem
    onRemove:(id:number)=>Promise<void>
}
```

CartItem type:

```ts
interface CartItem{
    id:number
    name:string
    image:string
    price:number
    quantity:number
}
```

Coding rules:

- Gunakan TypeScript
- Gunakan Tailwind utility class
- Gunakan ShadCN component
- Jangan gunakan inline style
- Hindari kode duplikat
- Gunakan reusable component
- Buat kode clean dan mudah di-maintain
- Pastikan responsive:
    - Mobile
    - Tablet
    - Desktop

Output:

- Tampilkan semua file yang perlu dibuat
- Sertakan path file
- Sertakan kode lengkap
- Jangan gunakan placeholder
- Pastikan kode dapat langsung dijalankan
- Pastikan tidak ada TypeScript error
