Tugas:

Tambahkan fitur search box untuk memudahkan user mencari produk pada halaman toko online (katalog) menggunakan Next.js, TypeScript, Tailwind CSS, dan ShadCN UI.

Stack:
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- ShadCN UI

Tujuan:

Memungkinkan user mencari produk secara cepat berdasarkan nama produk, kategori, atau keyword terkait dari daftar produk yang tersedia.

---

## Requirement Fungsional

Buat fitur search yang:

- Mencari produk berdasarkan:
  - nama produk (`name`)
  - kategori (`category`)
- Case-insensitive (tidak sensitif huruf besar/kecil)
- Real-time search (hasil langsung berubah saat user mengetik)
- Bisa menangani input kosong (menampilkan semua produk kembali)
- Tidak error saat data kosong

---

## UI Requirement

Gunakan komponen ShadCN:

- Input
- Button (optional untuk clear/search)
- Icon (Search, X)

Contoh UI:

```tsx
<Input placeholder="Search products..." />
```

Tambahkan:

- Icon search di dalam input
- Tombol clear input (optional)
- Responsive design (mobile-first)

---

## Behaviour

### 1. Default state

- Semua produk ditampilkan

### 2. User mengetik di search box

- Filter produk secara real-time

Contoh logic:

- input: `"nike"`
- hasil: semua produk dengan nama mengandung "nike"

---

### 3. Clear search

- Jika input dikosongkan:
  - tampilkan semua produk kembali

---

## Search Logic Requirement

Buat fungsi reusable:

```
lib/product-search.ts
```

### Function:

```ts
searchProducts(products: Product[], query: string): Product[]
```

### Rules:

- Match dari `name` dan `category`
- Case-insensitive
- Trim whitespace
- Jika query kosong → return semua products
- Tidak mengubah original array (pure function)

---

## Product Type

```ts
interface Product {
  id: number
  name: string
  image: string
  price: number
  category: string
}
```
