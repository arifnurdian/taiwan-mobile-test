Tugas:
Re-create tampilan halaman utama toko online (halaman katalog / storefront) dari file tersebut ke Next.js menggunakan Tailwind CSS dan ShadCN UI.

Stack yang wajib digunakan:
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- ShadCN UI

Tujuan:
Lakukan konversi HTML menjadi implementasi modern berbasis Next.js dengan mempertahankan tampilan dan pengalaman pengguna semirip mungkin dengan file referensi.

Coding rules:

- Gunakan TypeScript
- Gunakan App Router Next.js
- Gunakan utility Tailwind
- Jangan gunakan inline style
- Jangan gunakan CSS custom kecuali benar-benar diperlukan
- Jangan menggunakan file CSS terpisah jika dapat digantikan dengan Tailwind
- Gunakan semantic HTML
- Hindari kode duplikat
- Gunakan reusable component
- Gunakan naming convention yang konsisten
- Buat kode mudah dibaca dan mudah di-maintain
